# SegmentedControl

Pillerformad grupp där exakt ett alternativ är valt.

Behållare `surface-primary-100`, valt alternativ `button-primary-dark` med vit text. Text- eller ikonvariant.

Konsumenten ger: `items` (`{value,label,icon?}` – med `icon` blir `label` skärmläsartext), `value`/`defaultValue`, `onChange`, `label` för gruppen.
