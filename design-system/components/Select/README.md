# Select

Rullgardinsmeny byggd på en native `<select>` med varumärkets yta och en fylld pil.

Radie `radius-heavy`, text i fetstil 18 px, hover `button-primary-20`, aktiv `button-primary-40`, disabled `font-disable-dark`.

Konsumenten ger: `options` (texter eller `{value,label,disabled}`), `value`/`defaultValue`, `onChange`, `label`, `helper`, `placeholder`, `disabled`.

Obs: den öppna listan ritas av webbläsaren. Behövs en egen lista, bygg den med ListItem.
