# Tabs

Flikar för att växla mellan vyer på samma sida.

Vald flik: `font-brand` med 3 px linje i `surface-brand`. Hover: `surface-primary-100` och grå linje. Disabled: `font-disable-dark`.

Konsumenten ger: `items` (`{value,label,disabled}`), `value`/`defaultValue`, `onChange(value)`. Innehållspanelen ritar konsumenten själv.
