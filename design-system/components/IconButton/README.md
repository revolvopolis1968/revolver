# IconButton

Rund knapp med bara en ikon, för expandera, mer och liknande sekundära handlingar.

Storlekar `mini` 24, `small` 32, `default` 40; varianter `default` (transparent) och `secondary` (vit fyllnad). Kontur `stroke-dark-15-pct`, radie `radius-rounded`.

Konsumenten ger: `label` (krävs – blir `aria-label`), `icon` (namn eller SVG-element, standard `chevron-down`), `onClick`.
