# Notification

Mörk notis som konstaterar ett läge och erbjuder handlingar.

`surface-primary-dark`, ikon och rubrik i vitt, brödtext `font-medium-emphasis-light`, knappar i `secondary-ondark` och `primary`.

Konsumenten ger: `title`, brödtext som `children`, `actions`, `icon` (standard `info`), `onClose`. Rubriken konstaterar läget: "Det finns osparade ändringar".
