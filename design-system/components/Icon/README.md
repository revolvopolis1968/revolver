# Icon

Platshållarikoner som komponenterna använder internt.

**Obs:** varumärkets egen ikonuppsättning finns inte i systemet än. De här glyferna är enkla linjeteckningar som ersättare och ska bytas när ikonfilerna laddas upp. Alla ikonprops tar också ett eget SVG-element.

Konsumenten ger: `name`, `size` (`icons-*`: 12, 16, 18, 20, 24), `title` om ikonen bär betydelse.
