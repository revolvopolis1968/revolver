# Tooltip

Kort förklaring på mörk yta, med pil mot det den hör till.

`surface-primary-dark`, vit text, radie `radius-subtile`. Placering: `none`, `top`, `top-left`, `top-right`, `bottom`, `bottom-left`, `bottom-right`, `left`, `right`.

Konsumenten ger: texten, `placement`, `onClose` (visar kryss), och själva positioneringen mot målelementet.
