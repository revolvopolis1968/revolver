# Link

Fristående länk med pil, för "läs mer" och vidare-navigering.

Fet, understruken, `font-link` → `font-link-hover`. Storlekar `small` 16, `default` 18, `large` 22. Länkar i löptext använder stilen `content-body-link` i stället.

Konsumenten ger: texten, `href`, `size`, `arrow={false}` för att dölja pilen, `disabled`.
