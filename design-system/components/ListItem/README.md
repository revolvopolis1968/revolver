# ListItem

Rad i en lista eller meny som går att välja.

56 px hög, hover `surface-primary-100`, aktiv `surface-primary-300`. Vald rad visar bock; `checkbox` visar en kryssruta i stället.

Konsumenten ger: texten, `selected`, `checkbox`, `disabled`, `onClick`. Lägg raderna i ett element med `role="listbox"`.
